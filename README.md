Meu Primeiro Dashboard em Excel com IA
📌 Sobre o projeto
Este projeto apresenta meu primeiro Dashboard desenvolvido no Excel com apoio da Inteligência Artificial (IA).
O objetivo é transformar dados em informações visuais por meio de tabelas, gráficos e indicadores, facilitando a análise e a compreensão dos resultados.
🎯 Objetivos
Aprender a organizar dados no Excel;
Criar gráficos e indicadores;
Desenvolver um Dashboard visual e funcional;
Utilizar a Inteligência Artificial como ferramenta de apoio;
Praticar análise e apresentação de dados.
🛠️ Tecnologias utilizadas
📗 Microsoft Excel
🤖 Inteligência Artificial
📊 Gráficos e indicadores
📈 Dashboard para visualização de dados
📂 Estrutura do projeto
Planilha Excel: dados utilizados no projeto;
Dashboard: apresentação visual dos principais resultados;
Gráficos: representação dos dados;
Indicadores: resumo das principais informações.
